# Totherise

Agency website for **Totherise** - web development, AI automation and digital marketing services.

- Live: https://totheriseprivate.vercel.app

## Tech stack

- React 19 + Vite
- Tailwind CSS
- Framer Motion

## Getting started

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

## Structure

```
src/     pages, sections and styles
public/  static assets
dist/    last production build (generated)
```
